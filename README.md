# 预设换皮 Preset Reskin

SillyTavern 扩展。让 AI 把聊天补全预设里的文字换一种说法，另存为新预设。宏、标签、正则和脚本都原样保留。

适合预设被渠道按特征识别、需要换一版措辞的场景。只换说法，不改功能。

## 安装

在酒馆的扩展面板点「安装扩展程序」，填入本仓库地址，然后刷新页面。

## 使用

扩展面板里展开「预设换皮」，点「打开预设换皮」，按顺序操作：

1. **源预设**：选一个预设，或者导入 JSON 文件。选的是当前正在用的预设时，会按界面上的实时状态读取，没点保存的开关和改动也会带上。
2. **改写用的 AI**：可以用当前主 API，也可以填一个独立的 OpenAI 兼容接口。用独立接口时建议把「思考」设为关闭，速度会快很多。
3. **方向**：写上想换成的人物或口吻，留空就让 AI 自己发挥。点「AI 分析」会自动生成名称替换表和风格卡，生成后可以手改。
4. **模块**：勾选要改写的模块。大段纯文本可以勾「填充」，换成插件自带的公版书节选。
5. **运行**：改写完逐个对照原文检查，不满意的取消勾选，取消的模块保留原文。最后另存为新预设，或者下载 JSON。

## 怎么保证不坏

- 宏（`{{...}}`）、XML 标签、代码、URL、正则要匹配的字面量、SPreset 说话人标签都会被锁住，AI 改不到。
- 每段改写回来都会检查：占位符、行数、行首格式、语言、宏边界、说话人有没有被弄乱。不合格就重发，重发几次还不行就保留原文。
- 新预设除了文字，其余字段和原预设完全一致，正则、脚本、开关、顺序都原样保留。

## 隐私

- API Key 默认只留在内存里。勾选「记住 Key」后，会以明文存进酒馆的设置文件。
- 使用独立接口时，预设内容会直接发给你填写的那个服务商。

## 其他

- `books/` 是公版书节选，来自 Project Gutenberg。
- 离线测试：`PRESET_DIR=预设所在目录 node test/offline_test.mjs`
